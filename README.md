## Selected engineering work

- **Multi-region failover** — Designed and rolled out a two-region architecture with global load balancing, automated health checks and failover. The design kept critical customer operations running through maintenance and outages.
- **Enterprise customer ownership** — Served as the primary SRE contact for a customer handling **~85 million API calls per week**. Led weekly architecture discussions and built proofs of concept to validate proposed production changes.
- **Cloud migration and capacity planning** — Used canary tests, error rates, and latency to guide a staged migration from on-premises infrastructure to IBM Cloud. Adjusted Kubernetes replica counts, node capacity, and resource limits as traffic shifted.
- **API performance testing** — Built and maintained a multithreaded Python tool with configurable concurrency, request rates, and payload sizes. It generated reports to verify critical API operations during maintenance.
- **Developer tooling** — Built Python tools used by **5+ engineers** to switch Kubernetes clusters across cloud accounts. Automated log collection, cutting a 30+ minute manual workflow to 2–3 minutes.
- **Sev 1 incident response** — Handled Sev 1 production incidents roughly every two weeks and took weekend on-call shifts every three weeks. Led engineers during critical incidents and coordinated with Support and Development on escalations.
